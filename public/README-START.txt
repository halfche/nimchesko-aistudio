nimchesko AI studio — Cross-Platform Offline Package
====================================================

1. WINDOWS
   Extract this archive and double-click:
     run-windows.bat
   (Uses Python, Node.js, or built-in Windows PowerShell automatically.)

2. LINUX
   Extract this archive, then run in Terminal:
     chmod +x run-linux.sh
     ./run-linux.sh

3. INSTALL AS DESKTOP APP (Optional)
   When http://localhost:4173 opens in Chrome or Edge, click "Install App"
   in the top bar to install it as a standalone desktop window.

4. CONNECT LOCAL OLLAMA
   Ensure Ollama allows local browser requests:
     OLLAMA_ORIGINS=* ollama serve
